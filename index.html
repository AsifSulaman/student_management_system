About This Project

This is an educational Student Management System for a fictional university. I built it to practice:

  • HTML
  • CSS
  • JavaScript
  • Data structures
  • DOM manipulation
  • Local storage
  • Basic data processing
  • GPA calculation
  • Responsive web design

All names and records are made up. Data stays in your own browser and is never sent anywhere.

  • Handling user input
  • Manipulating the DOM
  • Storing data in the browser
  • Building reusable functions
  • Implementing GPA calculations
  • Designing responsive interfaces
